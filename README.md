# Форма — твой старт

Программа full body для начинающих с реалистичными AI-GIF, двумя тренировками и отметками подходов.

Статический сайт: HTML, CSS, JavaScript. Все изображения включены в репозиторий. Сборка и внешние сервисы не нужны. Прогресс хранится в localStorage браузера.

## Публикация

GitHub Pages: Deploy from a branch → main → / (root).

Для редактирования: index.html — структура, style.css — оформление, app.js — программа и интерактивность.

Все 12 GIF созданы с помощью AI в едином стиле. Кадры анимации сгенерированы, это не видеосъёмка. Иллюстрации не заменяют очную проверку техники. Ягодичный мост показан с мягкой накладкой и штангой; начинающим сначала освоить движение без веса.
