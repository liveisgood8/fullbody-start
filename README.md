# Форма — твой старт

Программа full body для начинающих с реалистичными AI-GIF, двумя тренировками и отметками подходов.

Статический сайт: HTML, CSS, JavaScript. Все изображения включены в репозиторий. Сборка и внешние сервисы не нужны. Прогресс хранится в localStorage браузера.

## Публикация

GitHub Pages: Deploy from a branch → main → / (root).

Для редактирования: index.html — структура, style.css — оформление, app.js — программа и интерактивность.

Все 14 GIF созданы с помощью AI в едином стиле. Кадры анимации сгенерированы, это не видеосъёмка. Иллюстрации не заменяют очную проверку техники. Ягодичный мост показан с мягкой накладкой и штангой; начинающим сначала освоить движение без веса.

Тренировка 01: бабочка в тренажёре; тренировка 02: разведение гантелей лёжа. Горизонтальная тяга показана на нижнем блоке сидя без упора грудью. Анимации содержат 12 сгенерированных фаз движения вместо 4–6.

В первой тренировке — сплит-приседания с гантелями, во второй — разгибание ног сидя. Кнопка тренера: https://t.me/liveisgood8. Вводные рекомендации размещены перед программой. GIF остаются покадровыми AI-иллюстрациями; полноценная плавность видео пока не достигнута.
